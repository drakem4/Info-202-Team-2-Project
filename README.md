# INFO 202 Pokédex Project

## Project Description

This project is a web-based Pokédex created for our INFO 202 project.

The website will allow users to search for Pokémon by name or
Pokédex number and display information about the selected Pokémon.

The project will use HTML, CSS, Bootstrap, JavaScript, and integrate the
PokéAPI.

## API

This project uses the PokéAPI to retrieve Pokémon data.

PokéAPI Documentation:
https://pokeapi.co/docs/v2

## Planned Features

- Search for Pokémon by name or Pokédex number
- Display Pokémon images
- Display Pokémon types
- Display Pokémon stats
- Responsive design for desktop and mobile devices
- Contact form
- Group member information page

## Setup

No installation is required.

To run the website locally:

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

A live version of the website will also be deployed using
GitHub Pages.
